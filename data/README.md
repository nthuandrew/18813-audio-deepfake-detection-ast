# Dataset setup

This project uses the **ASVspoof 2019 Logical Access (LA)** dataset for binary classification of bona fide and spoofed speech. The LA subset contains genuine speech together with text-to-speech (TTS) and voice-conversion (VC) attacks.

Do not commit datasets, extracted features, generated audio, or model checkpoints to Git. The repository `.gitignore` excludes everything under `data/` except this file.

## Official sources

- [ASVspoof 2019 website](https://www.asvspoof.org/index2019.html)
- [University of Edinburgh DataShare record](https://datashare.ed.ac.uk/items/31074a11-b6f6-4e92-a4ad-07093f8c0c45)
- Dataset DOI: [`10.7488/ds/2555`](https://doi.org/10.7488/ds/2555)
- [ASVspoof 2019 evaluation plan](https://www.asvspoof.org/asvspoof2019/asvspoof2019_evaluation_plan.pdf)

The official `LA.zip` archive is publicly accessible without an Edinburgh account. Its current compressed size is 7,640,952,520 bytes (approximately 7.12 GiB).

## Storage requirements

Check available disk space before downloading:

```bash
df -h .
```

Keep at least 25 GB available for the archive and extracted audio. More space will be required for cached Mel-spectrograms, checkpoints, and experiment outputs.

## Download

Run all commands from the repository root.

Create the local data directory:

```bash
mkdir -p data/raw/asvspoof2019
```

Download from the official Edinburgh DataShare endpoint:

```bash
curl -L \
  --fail \
  --continue-at - \
  --output data/raw/asvspoof2019/LA.zip \
  "https://datashare.ed.ac.uk/server/api/core/bitstreams/a9f87c35-f055-4015-80e2-2fdff0d46269/content"
```

The `--continue-at -` option makes the download resumable. If the transfer is interrupted, run the same command again.

## Verify the archive

Expected MD5 checksum:

```text
30c98f11d8b2bc21f2c257bfd78bb5c5
```

On macOS:

```bash
md5 data/raw/asvspoof2019/LA.zip
```

On Linux:

```bash
md5sum data/raw/asvspoof2019/LA.zip
```

Do not continue if the checksum differs. Delete the incomplete or corrupted archive and download it again.

## Extract the archive

Inspect the archive before extraction:

```bash
unzip -l data/raw/asvspoof2019/LA.zip | head -30
```

Extract it:

```bash
unzip data/raw/asvspoof2019/LA.zip \
  -d data/raw/asvspoof2019
```

## Dataset partitions

| Partition | Bona fide | Spoof | Total | Attack coverage |
| --- | ---: | ---: | ---: | --- |
| Train | 2,580 | 22,800 | 25,380 | A01-A06 |
| Development | 2,548 | 22,296 | 24,844 | A01-A06 |
| Evaluation | 7,355 | 63,882 | 71,237 | A07-A19 |

Training and development contain known attacks. The evaluation set contains two attacks related to known systems and eleven attacks generated by previously unseen systems. This makes the official evaluation partition suitable for the project's unseen-attack analysis.

The partitions are highly imbalanced, so accuracy must not be reported alone. The primary evaluation should also include Equal Error Rate (EER), and may include precision, recall, F1, and ROC-AUC.

## Countermeasure protocols and labels

Use the official countermeasure (CM) protocol files as the source of labels:

```text
ASVspoof2019_LA_cm_protocols/
├── ASVspoof2019.LA.cm.train.trn.txt
├── ASVspoof2019.LA.cm.dev.trl.txt
└── ASVspoof2019.LA.cm.eval.trl.txt
```

Each row contains five whitespace-separated fields:

```text
speaker_id utterance_id unused attack_id label
```

The `label` is either `bonafide` or `spoof`. The `attack_id` is `-` for bona fide samples and an ID such as `A01` through `A19` for spoofed samples. The audio filename is `{utterance_id}.flac`.

This project uses the following binary encoding:

```text
bonafide = 1
spoof    = 0
```

Keep this encoding consistent in preprocessing, training, score interpretation, metrics, and reporting.

## Minimal Python access example

Install the basic reader dependencies in the project environment:

```bash
python -m pip install pandas soundfile
```

The following example loads the training protocol and reads one FLAC file:

```python
from pathlib import Path

import pandas as pd
import soundfile as sf

la_root = Path("data/raw/asvspoof2019/LA")
split = "train"

protocol_path = (
    la_root
    / "ASVspoof2019_LA_cm_protocols"
    / "ASVspoof2019.LA.cm.train.trn.txt"
)

columns = [
    "speaker_id",
    "utterance_id",
    "unused",
    "attack_id",
    "label",
]

metadata = pd.read_csv(
    protocol_path,
    sep=r"\s+",
    names=columns,
)

audio_dir = la_root / f"ASVspoof2019_LA_{split}" / "flac"
metadata["path"] = metadata["utterance_id"].map(
    lambda utterance_id: audio_dir / f"{utterance_id}.flac"
)
metadata["target"] = metadata["label"].map(
    {"bonafide": 1, "spoof": 0}
)

row = metadata.iloc[0]
audio, sample_rate = sf.read(row["path"])

print(row["utterance_id"])
print(row["label"])
print(row["attack_id"])
print(audio.shape)
print(sample_rate)  # Expected: 16000
```

Before training, verify that every protocol entry resolves to an existing audio file and that the number of parsed rows matches the official partition counts.

The repository includes a validator that performs both checks for all three
partitions. After installing the project dependencies, run:

```bash
add-validate-data --la-root data/raw/asvspoof2019/LA
```

For a quick protocol-only check that does not scan all FLAC paths:

```bash
add-validate-data \
  --la-root data/raw/asvspoof2019/LA \
  --skip-audio-check
```

Expected success message:

```text
Dataset validation PASSED
```

If extraction produced an additional nesting level, pass the actual directory
that directly contains `ASVspoof2019_LA_cm_protocols`, and make the same change
to `data.la_root` in the experiment config.

## Experimental use

- Preserve the official train, development, and evaluation partitions.
- Use the development set for model selection and threshold tuning.
- Do not tune preprocessing, hyperparameters, or thresholds using evaluation labels.
- Report results across the five planned random seeds.
- Record the per-seed configuration, checkpoint, and predictions.
- Report performance on the complete evaluation set and, where useful, break down results by attack ID.
- Apply synthetic background noise only according to the documented robustness protocol.

The original ASVspoof 2019 challenge rules prohibit external speech data and externally trained components. This course project plans to fine-tune a pretrained AST, so its results should be described as a course research experiment using ASVspoof 2019, not as an official challenge-compliant submission. Document the pretrained checkpoint and all external resources in the final report.
